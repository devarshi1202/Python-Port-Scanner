# Networking Concepts Demonstrated

- **IP address:** identifies a host on an IP network.
- **TCP:** connection-oriented transport protocol used by many application services.
- **Port:** a logical endpoint used by transport-layer services.
- **Socket:** programming interface used here to create TCP connections.
- **Connect scan:** this project tests whether a TCP connection can be established.
- **Timeout:** limits how long the program waits for a connection attempt.

The project is intentionally simple so that the networking mechanism is visible in the Python code.
